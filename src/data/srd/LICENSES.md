# SRD data licensing

The JSON files in this folder are generated by `pnpm srd:import` from the official
System Reference Document 5.2.1 PDF (https://www.dndbeyond.com/srd).

`pnpm srd:verify` cross-checks structured values against two open datasets, which
are downloaded at pinned commits into `.cache/` and are not redistributed:

- 5e-bits/5e-database (MIT License, Copyright (c) [2018-2020] [Adrian Padua, Christopher Ward])
- Open5e (open5e-api; SRD content is licensed by its publishers)
